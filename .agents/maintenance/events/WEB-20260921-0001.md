# WEB-20260921-0001: Harden the CI and Pages toolchain baseline

## Summary

Pinned the Website toolchain and upgraded GitHub Pages workflows to Node-24-native actions on Ubuntu 24.04.

## Reason

GitHub-hosted runner and action-runtime migrations made the prior floating runner and Node 20 action dependencies time-sensitive. A tracked cross-platform toolchain baseline also reduces version drift between Windows, WSL, and CI.

## Actions

Added a minimal mise configuration for Node.js, npm, and Python; declared matching Node.js and npm requirements in package metadata; pinned CI to Node.js 24.14.1, npm 11.19.1, and Ubuntu 24.04; upgraded the Pages artifact and deployment actions to v5; and documented the local workflow.

## Validation

Confirmed Node.js 24.14.1 and npm 11.19.1 locally, installed dependencies with `npm ci`, ran the complete automated test suite with zero failures, built 136 Astro pages, generated Pagefind indexes for 42 pages in two languages, ran repository rule validation, and passed `git diff --check`.

## Result

The repository now has an explicit lightweight toolchain contract while preserving Astro static output, the protected Pages deployment sequence, and Linear Release integration.

## Rollback

Revert this event's configuration, workflow, package metadata, and development-documentation changes together, then restore the previous Pages action majors and runner declarations.

## Follow-up

Verify the Ubuntu 24.04 PR check and the automatic protected-main Pages deployment before closing HC-124.

## Notes

The local host could parse the mise configuration but could not install its Python tool into a host-managed system directory. GitHub Actions remains the authoritative Linux verification for the declared Python 3.11 line.
