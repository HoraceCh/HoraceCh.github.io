# Round keyboard-focus indicators

## Summary

Add a small rounded focus shape to ordinary native controls while preserving component-specific corners and visible outlines.

## Reason

Ordinary text links had square focus corners, and mobile Notes outline links lacked a usable inherited focus color.

## Actions

Added a zero-specificity focus-only radius rule. Existing Header, fields, pills and Notes control radii retain ownership. Reused the shared focus ring for Notes sidepane contrast and supplied its mobile outline fallback. No content, geometry, click-target, navigation lifecycle or motion change was made.

## Validation

Pinned Node 24.14.1 and npm 11.19.1 build passed with 137 routes and 43 indexed pages. Full repository tests passed 202 of 202. Real Chrome keyboard before/after observations cover both themes, representative routes, Menu, Search, short windows, multiline links and active forced colors. A focused regression first failed on the predecessor mobile outline without a visible outline.

## Result

The scoped local focus treatment is retained for independent accessibility and CSS review. Existing About native zoom and physical assistive-technology acceptance gaps are not passed by this change.

## Rollback

Revert this scoped stylesheet change and event, then rebuild the generated maintenance index.

## Follow-up

Keep outstanding native accessibility evidence separate from the shared focus styling checkpoint.

## Notes

No dependency, runtime, schema, route, publication or deployment change was introduced.
