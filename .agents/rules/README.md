# Rules

This directory stores stable project constraints.

- `maintenance-logging.md`: the sole canonical maintenance logging policy and v2 record schema.
- `persistence-boundaries.md`: Rules / Skills / Memory / Maintenance / legacy Changelog boundaries.
- `safety-validation.md`: repository editing and behavior-matched validation requirements.
- `audit-trail.md`: compatibility pointer for the closed legacy v1 audit trail.

Do not copy maintenance decision rules or schema definitions into another rule file. Link to `maintenance-logging.md` instead.
