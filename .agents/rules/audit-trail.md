# Legacy Audit Trail

`.agents/changelog.md` is the immutable System Maintenance Log v1 audit trail. It remains available for historical context, but it is closed to new entries and must not be reordered, rewritten, or migrated into v2 records.

Use `.agents/rules/maintenance-logging.md` for every new logging decision and `.agents/maintenance/` for all new records. The `audit-update` Skill is retained only as a compatibility handoff to the v2 process.
